PyFormatWhy

Pick a value and a Python format spec, the part after the colon in f"{value:spec}" or format(value, spec). See the result, how the spec was read, and why.

Matches Python 3.10 (z and other 3.11+ options are errors here, as they are there). Not covered: Decimal, Fraction, datetime, bool, the locale-specific n (treated like the C locale), nested {} fields, !r conversions. Error wording is close to Python's but its check order differs, so only the fact that it errors is verified. About & tests
